# Four original Roblox Panjabi designs

Eight separate wearable PNG files: two fabric versions of each original design.

| Design | Textured, no folds | Textured, soft folds |
| --- | --- | --- |
| 08 Emerald Botanical — green with antique-gold vines, chest pocket and botanical cuffs | [PNG A](panjabi-original-08-emerald-no-folds.png) | [PNG B](panjabi-original-08-emerald-soft-folds.png) |
| 09 Burgundy Geometry — wine cloth with silver diamond placket, framed chest work and geometric cuffs | [PNG A](panjabi-original-09-burgundy-no-folds.png) | [PNG B](panjabi-original-09-burgundy-soft-folds.png) |
| 10 Teal Modern — teal with ivory chevron placket, asymmetric chest line and matching cuffs | [PNG A](panjabi-original-10-teal-no-folds.png) | [PNG B](panjabi-original-10-teal-soft-folds.png) |
| 11 Sand Kantha — beige with chocolate/ivory running stitches, chest pocket and stitched cuffs | [PNG A](panjabi-original-11-sand-no-folds.png) | [PNG B](panjabi-original-11-sand-soft-folds.png) |

Both fabric versions retain visible woven detail. A has no large folds; B adds gentle diffuse fold shading. No glossy cloth reflections. Each pair has the same design, collar, cuffs, buttons and pocket configuration.

All eight are 585 x 559 RGBA PNGs. Their real alpha channels match the approved Sample03 pixel-for-pixel, preserving neck and sleeve/hand openings. Outside the garment is opaque white with the `2.94` logo. No template outlines are included in the wearable PNGs.
