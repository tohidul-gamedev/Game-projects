# Four Panjabi designs from new demo.zip

Four separate Roblox Classic Shirt textures, based on the four supplied garment photographs. One soft-fold version per design; no additional no-fold copies.

| Reference file | Finished PNG | Design |
| --- | --- | --- |
| image 81.png | [12 Grey and white floral](panjabi-12-grey-white-floral.png) | Grey cotton with white vertical botanical garlands and diamond-floral motifs across torso and sleeves, short button placket. |
| image 82.png | [13 Black and bronze stripes](panjabi-13-black-bronze-stripes.png) | Near-black cotton with four narrow full-height embroidered front bands, patterned collar and layered cuff bands. |
| image 83.png | [14 Black and gold buta](panjabi-14-black-gold-buta.png) | Black cotton, sparse small gold botanical motifs on upper chest, plain lower torso/back/sleeves, short dark button placket. |
| image 84.png | [15 Maroon and red pinstripes](panjabi-15-maroon-red-pinstripe.png) | Wine/maroon vertical pinstripes across the garment, crimson embroidered collar and long pointed chest placket, matching striped sleeves. |

Each wearable file is an 8-bit 585 x 559 RGBA PNG. All use the approved Sample03 alpha mask exactly, with genuine neck and sleeve/hand transparency. The unused canvas is opaque white and carries the user's `2.94` logo. The garment regions contain visible woven texture and soft diffuse fold shading, without glossy reflection bands. Reference advertising text and brand marks are omitted.
