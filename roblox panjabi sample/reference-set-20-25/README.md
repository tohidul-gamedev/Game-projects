All wearable files are 585 x 559, 8-bit RGBA PNGs. The real alpha channel matches the approved Sample03 mask exactly, preserving the neckline and sleeve/hand openings. The unused canvas is opaque white with the user's `2.94` logo. Reference photographic backgrounds, advertisements and other brand marks are omitted. Back panels not visible in a photograph use coordinated cloth or print from that garment.
