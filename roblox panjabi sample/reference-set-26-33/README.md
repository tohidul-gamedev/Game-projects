# Eight reference-based Panjabi shirts: 26–33

Adapted in ZIP order from the eight clothing photographs in demo 3.zip. One textured, softly folded version per reference; no no-fold duplicates.

All wearable PNGs are 585 × 559, 8-bit RGBA. The approved Sample03 panel positions and exact genuine alpha mask are retained, with white unused canvas and 2.94 branding. No guide outlines or painted transparency checkerboard.
